# ケーブル物理 実装仕様(VCV Rack フォーク向け)

VCV Rack のパッチケーブルを、実機のパッチケーブルのように振る舞わせる改造の仕様です。
ブラウザで作った試作 `reference/cable-bench.html` が**動く正解**です。迷ったら試作のコードと見た目に合わせてください(ブラウザで開けばそのまま動きます)。

> 実装担当の Claude Code へ: まずこのファイルを最後まで読み、`reference/cable-bench.html` の `<script>` を読んでから着手してください。数値は試作と同じにしてください。

---

## 0. どこに実装するか

- この改造は **Rack 本体**(`VCVRack/Rack`)の改造です。モジュールのプラグイン側ではありません。
- Rack 本体をフォークした別リポジトリで作業します。プラグイン側のリポジトリは変更不要です。
- Rack 本体は GPLv3。自分で使う分には自由。配布する場合は GPL に従い、「VCV」の名前とロゴは使わないこと。
- 画面の確認は GUI が必要なので、ビルドと見た目の確認は利用者のローカル環境で行う想定です。クラウド側ではコードを書き、ビルドが通ることまでを確認してください。

## 1. 目標(決定事項)

1. **物理に忠実な垂れ方**。ケーブルは 3D の弾性棒。重力、曲げの硬さ、クセ(形の記憶)、パネル・ノブ・ほかのケーブルとの衝突を計算する。
2. **プラグは手前に突き出た剛体**。プラグとブーツはパネルから手前(z方向)にまっすぐ 2.6cm 出ている。ケーブルはブーツの先からまず手前に出て、そこから曲がる。
3. **触ったときだけ動き、落ち着いたら固定**。ずっと揺れ続けない。固定後は物理計算ゼロ。
4. **描き方は2種類**: 「フラット」(単色+細い縁)と「立体」(Easel V 風の柔らかい円柱)。設定で切り替え。
5. **ケーブルの太さを変えられる**(直径 2.5〜6mm、既定 3.8mm)。
6. **プラグの電圧ランプは消す**。電圧はポートのツールチップで見る。
7. **パネルを斜めから見るカメラは無し**。Rack の画面は真正面(試作の「カメラの高さ 0°」)。奥行きは影のずれと重なり順で伝える。

## 2. 単位と座標

- 物理は **cm**。Rack は 1HP = 15px = 5.08mm なので、**1cm = 29.528px**(ズーム 100% 時、Rack のワールド座標)。
- x: 右、y: 下(Rack と同じ)、z: パネルから手前(パネル面が z=0)。
- 画面への投影は真正面: 画面座標 = (x, y) × 29.528。z は描画順と影にだけ使う。

## 3. ケーブルのモデル

| 名前 | 値 | 意味 |
|---|---|---|
| `LB` | 2.6 cm | プラグ+ブーツの突き出し長さ |
| `RC` | 0.19 cm(太さ 3.8mm の半径) | ケーブル半径。太さ設定で `RC = 直径mm / 20` |
| `RB` | `0.13 + RC * 1.25` | ブーツ半径(太さに連動) |
| `SEG` | 1.0 cm | 物理の点の間隔(目安) |
| 長さ | 15, 30, 45, 60, 90, 120, 150 cm | 自動選択: `距離*1.1 + 2*LB + 3` 以上の最短 |

点の並び(1本あたり `n = m + 3` 点、`m = round((長さ - 2*LB) / SEG)`):

- `0`: ジャックA の根元(z=0)固定
- `1`: ジャックA のブーツ先端(z=LB)固定
- `2 .. n-3`: 自由な点
- `n-2`: ジャックB のブーツ先端(z=LB)固定
- `n-1`: ジャックB の根元(z=0)固定

固定点は逆質量 `w = 0`、自由な点は `w = 1`。根元の点を曲げ拘束に含めることで、ケーブルがブーツから手前にまっすぐ出る向きが保たれる。

### 3.1 拘束(PBD)
- 距離拘束 `i, i+1`(剛性 1)
- 曲げ拘束 `i, i+2`(剛性 `kb`)と `i, i+3`(剛性 `kb * 0.55`)。静止長は「まっすぐなときの長さ」から始まり、クセで変わる(3.3)。
- `kb = 0.003 + 0.3 * stiff^2.5`(`stiff` は 0〜1)

### 3.2 初期形状
挿した瞬間の形は、ジャック間の弦と「向き」ベクトルが張る面内の円弧(弧長 = 自由長)。
- 短いケーブル(`自由長 / 距離 > 2.5` かつ `自由長 < 26cm`)は上向きの輪: 向き `(0, -0.8, 0.6)`
- それ以外は下向き: 向き `(0, 0.75, 0.66)`
- 向きは弦に直交化してから使う。円の半径は二分法で弧長が合うように解く(試作 `makeCable` 参照)。

### 3.3 クセ(形の記憶)
- 挿したとき: 曲げ拘束の静止長を、初期形状の距離へ `mem * 0.8` だけ寄せる。
- 手で曲げたとき: ドラッグ中とその後しばらく、毎ステップ静止長を現在の距離へ `0.04 * mem * plast` だけ寄せる。`plast` はドラッグ中 1、離した後は毎ステップ ×0.96。
- これが「短い輪が上に立つ」「手で整えた形が残る」の正体。曲げの硬さだけでは輪は立たない。

### 3.4 1ステップ(dt = 1/60 s、サブステップ 2、反復 16)
```
g   = 981 * 0.9 * weight^2 + 6              // weight は 0〜1
th  = ケース傾き(度→rad)
重力 = (0, g*cos(th), -g*sin(th)) * h^2       // h = dt / 2。傾けるとパネル側へ押される
減衰 damp = ドラッグ中 0.9 / 通常 0.93 / 固定前の最後20フレームは 0.6〜0.93
for サブステップ 2回:
  Verlet 積分(速度 * damp + 重力)
  for 反復 16回:
    距離拘束、曲げ拘束 i+2、曲げ拘束 i+3
    4反復ごとに: ケーブル同士の衝突 → 静的な衝突
```
PBD は反復回数と dt で硬さの感じ方が変わるので、**この回数と dt は試作と同じ**にすること。

### 3.5 衝突
- **パネル面**: `z < RC` なら `z = RC`。
- **机**: ケース下端 + 1.1cm に水平な面。Rack 上で机を表現しないなら省略してよい(その場合、長いケーブルはラックの下へ垂れていく)。要相談。
- **ノブ・スイッチ・ジャック**: 縦向きの円柱(半径 R、高さ H)。中に入ったら、上面に乗せるか横へ押し出すか、めり込みが浅い方を選ぶ。自分のプラグのブーツは、端から3点まで無視する。
- **ケーブル同士**: 線分同士の最近点で `2*RC` 未満なら押し離す(補正 ×0.8)。空間ハッシュ(セル 1.2cm)。同じケーブルの近い線分(index 差 3 以下)は無視。
- **摩擦**: パネル・机・ノブ上面に接したとき、1ステップの滑りが 0.02cm 未満なら止める(静止摩擦)。それ以上なら 0.3〜0.4 だけ減速。これが無いと長いケーブルがずっと滑り続ける。

### 3.6 起こす・固定する
- 普段は物理を回さない。
- **起こすきっかけ**: ケーブルの追加・削除、ドラッグ、物理系の設定変更(硬さ・重さ・クセ・傾き・太さ)。起きた瞬間に速度をゼロにする(`prev = 現在位置`)。
- 起きている間: ドラッグ中は 1フレーム 1ステップ、離した後は 1フレーム 4ステップ(素早く落ち着く)。
- **固定**: 最大移動が 0.004cm/ステップ 未満の状態が 12フレーム続く、または 約100フレーム経過。最後の 20フレームで減衰を強めてから止める。

## 4. 描画

### 4.1 滑らかにする(必須)
物理の点をそのまま線でつなぐとカクつく。描画用に:
1. 3D で 1回だけ平滑化(自由な点を 隣:自分:隣 = 1:2:1 で平均)
2. Catmull-Rom スプラインで 1区間を 5分割
3. スプラインの端は根元の点(z=0)を制御点に使う

### 4.2 重なり順
- 真正面なので、奥行き = z(パネルからの高さ)。
- ケーブルを短い区間(スプラインの 10点ずつ)に分け、ブーツと一緒に z の低い順に描く。
- ブーツは中点(z = LB/2)を奥行きとする。

### 4.3 フラット
- 区間ごとに「縁(太さ w+1、暗い色)を自分の範囲だけ」→「本体(太さ w)を前後2〜3点はみ出して」描く。はみ出しで継ぎ目が隠れる。
- 色: 縁は本体を黒へ 32% 寄せる。暗い色(黒)の縁は白へ 16% 寄せる。

### 4.4 立体(Easel V 風)
5本の線を重ねる。明るい線ほど光の方向へずらす。
| 太さ(w比) | 色 | ずらす量(w比) |
|---|---|---|
| 1.0 | 黒へ 50%(暗い色は 35%) | 0 |
| 0.84 | 黒へ 26%(暗い色は 10%) | 0.07 |
| 0.64 | 本体色 | 0.13 |
| 0.40 | 白へ 20%(暗い色は 12%) | 0.19 |
| 0.17 | 白へ 70%(暗い色は 40%)、不透明度 0.9 | 0.25 |

- 光の方向(画面)`L = (-0.45, -0.89)`(左上)。各点のずらしベクトル = 法線 × (法線・L)。曲がりに沿って連続的に変わるので、ハイライトが反対側へ飛ばない。
- **継ぎ目に暗い輪(節)が出る問題**: 区間ごとに5本描くと、隣の区間の暗い線の端が明るい線の上に乗る。試作では各区間を「その区間だけの帯の形」でクリップして解決した。NanoVG は任意形状のクリップができない(`nvgScissor` は四角だけ)ので、**Rack では立体スタイルのときケーブル1本を区間に分けずに連続で描き、ケーブル単位で平均 z の低い順に並べる**こと。交差の前後が途中で入れ替わる珍しいケースは諦める。
- 太さ w は区間ごとに変えず、ケーブル1本で1つにそろえる。
- ブーツ: 側面は光の方向への線形グラデーション、先端の面は光の方向へずらした放射グラデーション(`nvgLinearGradient`, `nvgRadialGradient`)。

### 4.5 影
- 光の向き(3D)`LIGHT = normalize(-0.35, -0.8, 1.0)`。点 P の影は `P - LIGHT * (P.z / LIGHT.z)` をパネル面へ落としたもの。
- 濃さ `0.38 * shadow * exp(-z/7)`、太さ `2*RC * (1 + z*0.12)`。区間の端は丸めない(butt)。丸めると重なりが濃い輪になる。
- 立体スタイルでは、同じ線を 2.2 倍の太さ・0.35 倍の濃さでもう1本描いてぼかす。
- ブーツの影は根元から影の点までの線。

### 4.6 ブーツ(プラグ)
- 根元(z=0)と先端(z=LB)を結ぶ筒。真正面では先端の円がほぼ全部。
- 根元に近い側にリブを3本(0.66, 0.78, 0.9 の位置)。
- 色はケーブルと同じ。

### 5.1 当たり判定はモジュールから自動で取る
新しいモジュールを追加しても、モジュールごとの作業は不要にする。
- 各 `ModuleWidget` の子から `ParamWidget` と `PortWidget` を走査して、`box` の中心と大きさから円柱を作る。
- 高さの目安: ノブ(`Knob` 系)1.6〜2.2cm(大きいほど高く)、スイッチ・ボタン 1.0cm、ジャック 0.3cm。
- モジュールの追加・移動・削除で作り直す。

### 5.2 操作
- 今まで通り、プラグのドラッグで挿す・抜く・付け替え。
- 新しく「ケーブルの途中をドラッグして形を整える」。今の Rack はケーブル本体にマウス判定が無いので、ケーブル近く(画面上で半径+数px)のクリックをケーブル側で拾う。モジュールのドラッグや範囲選択とぶつかる場合は修飾キー付き(例: Alt+ドラッグ)にする。**要相談**。
- ドラッグ中は掴んだ点を `w = 0` にしてマウス位置へ置く(z は掴んだときの値を保つ)。

## 6. 進め方の提案

1. フォークを作り、手元のビルドが通る状態にする。
2. `CablePhysics`(点・拘束・積分・固定)だけを入れ、今の見た目のまま形だけ物理にする。
3. 衝突(パネル → 自動の当たり判定 → ケーブル同士)。
4. 描画(滑らか化 → フラット → 影 → ブーツ → 立体)。
5. 電圧ランプを消す、保存と読み込み、設定メニュー。
6. 途中をドラッグして整える操作。

各段階で、試作の同じ設定と見比べる。
